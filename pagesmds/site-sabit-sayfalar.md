# Site Sabit Sayfalar

**Menü Yolu:** Web Sitesi > Site Sabit Sayfalar
**URL:** https://www.apsiyon.com/manager/websiteConstantPage.aspx

## Genel Bakış
Web portalındaki sabit sayfaların (Hakkımızda, İletişim) içeriklerini düzenleme ekranıdır. Sadece okuma modunda.

## İçerik / Özellikler
İki sekme:
- **Hakkımızda Sayfası İçeriği** — Zengin metin editörü (format, başlık seviyeleri, harf tipi, punto seçimi)
- **İletişim Sayfası İçeriği** — İletişim bilgileri içeriği

## Notlar
- Sadece okuma modunda; "Kapat" butonu mevcut
- Web portaldaki statik "Hakkımızda" ve "İletişim" sayfalarının metni buradan yönetilir
