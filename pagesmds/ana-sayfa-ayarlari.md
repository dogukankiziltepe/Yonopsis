# Ana Sayfa Ayarları

**Menü Yolu:** Web Sitesi > Ana Sayfa Ayarları
**URL:** https://www.apsiyon.com/manager/website.aspx

## Genel Bakış
Site web portalının genel ayarlarının (isim, alan adı, sosyal medya) yapılandırıldığı sayfadır. Sadece okuma modunda.

## İçerik / Özellikler
- **Site Adı**
- **Başlık** (1. satır ve 2. satır)
- **Alt Alan Adı** (xxx.apsiyon.com)
- **Alan Adı** (özel domain)
- **Sosyal Medya:** Facebook, Instagram, Twitter, YouTube URL'leri

## Notlar
- Sadece okuma modunda; "Kapat" butonu ile kapatılır
- Alt alan adı sakinlerin eriştiği web sitesinin adresidir
