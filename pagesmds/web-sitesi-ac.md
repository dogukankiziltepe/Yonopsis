# Web Sitesini Aç

**Menü Yolu:** Web Sitesi > Web Sitesini Aç
**URL:** https://www.apsiyon.com/dashboard.aspx

## Genel Bakış
Site sakinlerinin kullandığı Apsiyon web portalına (dashboard.aspx) doğrudan bağlantı.

## İçerik / Özellikler
- Yönetici panelinden (manager/) sakin portalına geçiş bağlantısı
- Sakinlerin gördüğü arayüzü önizlemek için kullanılır

## Notlar
- apsiyon.com/dashboard.aspx adresine yönlendirir
- Sakin portalında: ödeme, duyuru, talep, profil vb. özellikler bulunur
