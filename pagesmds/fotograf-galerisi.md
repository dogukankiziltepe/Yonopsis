# Fotoğraf Galerisi

**Menü Yolu:** Web Sitesi > Fotoğraf Galerisi
**URL:** https://www.apsiyon.com/manager/gallery.aspx

## Genel Bakış
Sitenin web portalında yayınlanacak fotoğraf galerilerinin yönetildiği sayfadır. 1 kayıt.

## İçerik / Özellikler
- **Filtreler:** Alfabetik harf filtresi (Tümü, #, A-Z)
- **Sekme:** Hepsi
- **Tablo Sütunları:**
  - Galeri Adı
  - İmaj Sayısı
  - Gösterim Türü (Herkese Açık / Üyelere Özel)
  - Aktif
  - Vitrin (ana sayfada öne çıkarılsın mı)
- **Butonlar:**
  - `+` Yeni galeri
  - Excel dosyası olarak kaydet (XLS)

## Notlar
- Tek galeri mevcut: "Concord" — 4 imaj, Herkese Açık
