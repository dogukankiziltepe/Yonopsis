# Site Teması

**Menü Yolu:** Web Sitesi > Site Teması
**URL:** https://www.apsiyon.com/manager/theme.aspx

## Genel Bakış
Web portalının görsel temasının (logo, renk, font, arka plan) yapılandırıldığı sayfadır. Sadece okuma modunda.

## İçerik / Özellikler
- **Tema** seçimi
- **Site Yazı Fontu**
- **Menü Rengi**
- **Arka Fon Rengi**
- **Logo ve Arka Plan Görseli:** concord-istanbul.png (4813×1203, 550 KB)
- **Site Logosu**
- **Raporlar İçin Site Logosu**
- **E-Postalar İçin Site Logosu**
- **Site Arka Planı**
- **Alt Arka Plan**
- **Raporlar İçin İmza** (PDF/Excel raporlarında görünecek imza görseli)
