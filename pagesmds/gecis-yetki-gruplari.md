# Geçiş Yetki Grupları

**Menü Yolu:** Güvenlik > Tanımlar > Geçiş Yetki Grupları
**URL:** https://www.apsiyon.com/manager/gategroups.aspx

## Genel Bakış
Geçiş kartlarına atanacak yetki gruplarının tanımlandığı sayfadır. Her grup hangi kapılardan geçilebileceğini belirler. 5 kayıt.

## İçerik / Özellikler
- **Filtreler:** Alfabetik harf filtresi (Tümü, #, A-Z)
- **Sekme:** Hepsi
- **Tablo Sütunları:**
  - Grup Adı
  - Durumu (Açık / Kapalı)
  - Tipi (Kgs = Kart Geçiş Sistemi, Pts = Plaka Tanıma Sistemi)
- **Butonlar:**
  - `+` Yeni yetki grubu
  - Excel dosyası olarak kaydet (XLS)

**Mevcut Gruplar:**

| Grup Adı | Durum | Tip |
|---|---|---|
| Site Giriş 1 | Açık | Kgs |
| Site Giriş 2 | Açık | Kgs |
| Sosyal Tesis Giriş | Açık | Kgs |
| Bayan Sosyal Alan Giriş | Açık | Kgs |
| Otopark | Açık | Pts |

## Notlar
- Kgs (Kart Geçiş Sistemi): kart okutarak giriş
- Pts (Plaka Tanıma Sistemi): otomatik plaka okuma ile giriş (otopark)
- Geçiş kartlarına birden fazla yetki grubu atanabilir
